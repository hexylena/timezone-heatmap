Hexylena always struggled with the standard view of time, when planning global events. So now this exists

  • A more re-usable date picker you can share with others.
  • A hardcoded example with a heatmap. It is an interesting example of matching up a number of trainers with a number of trainees, and considering the overlap of both. I was worried we would have insufficient coverage in some regions.

Heavily inspired by WorldTimeBuddy.

AGPL-3.0, github.com/hexylena/timezone-heatmap.
